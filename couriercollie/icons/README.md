# Icons

The ~40 icons couriercollie's window uses, copied from KDE's Breeze icon theme (light and dark), so the app looks
right where Breeze isn't installed (e.g. on GNOME) without pulling in the whole theme. Used only for icons the
desktop's own theme doesn't have.
